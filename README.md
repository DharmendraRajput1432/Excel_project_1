# Excel Functions Practice – Student Data Analysis

## 📌 Project Overview

This project demonstrates practical use of Microsoft Excel 2021 functions to analyze student data, calculate ages, find student records, perform conditional calculations, and extract top-performing students.

The worksheet contains student information such as names, marks, dates of birth, fees, grades, and percentages. It also includes practice examples of lookup, text, logical, mathematical, and date functions.

## 🎯 Project Objectives

- Practice essential and advanced Excel formulas.
- Analyze student marks and fee information.
- Calculate student age and the difference between dates.
- Search for student records using lookup functions.
- Extract the top 5 students based on Mathematics marks.
- Apply rounding functions to numerical values.

## 📊 Dataset Description

## 🛠️ Excel Functions Practiced

### 1. Conditional Functions
- `COUNTIFS()` – Counts records that meet multiple conditions.
- `SUMIFS()` – Adds values that meet specified conditions.
- `AVERAGEIFS()` – Calculates averages based on conditions.
- `IF()` – Returns a result based on a logical test.

### 2. Lookup and Reference Functions
- `VLOOKUP()` – Searches for a value in the first column of a range.
- `XLOOKUP()` – Searches for a matching value and returns corresponding data.
- `INDEX()` – Returns a value from a specified position.
- `MATCH()` – Finds the position of a matching value.
- `XMATCH()` – Finds the relative position of an item.
- `INDIRECT()` – Creates a cell reference from text.
- `OFFSET()` – Returns a reference shifted from a starting cell.

### 3. Counting Functions
- `COUNT()` – Counts cells containing numbers.
- `COUNTIF()` – Counts cells matching one condition.

### 4. Date Functions
- `TODAY()` – Returns the current date.
- `DATEDIF()` – Calculates the difference between dates in years, months, or days.
- Age calculation using Date of Birth.
- Difference in days between two dates.

### 5. Text Functions
- `LEFT()` – Extracts characters from the beginning of text.
- `UPPER()` – Converts text to uppercase.
- `LOWER()` – Converts text to lowercase.
- Text extraction and name formatting.

### 6. Mathematical Functions
- `ROUND()` – Rounds a number to a specified number of digits.
- `CEILING()` – Rounds a number up to a specified multiple.
- `FLOOR()` – Rounds a number down to a specified multiple.

### 7. Data Extraction and Ranking
- Filter student records using conditions.
- Identify the top 5 students based on Mathematics marks.
- Retrieve student names and corresponding scores.
